# v1.4 C4b — music library expansion (plan)

Constraint from docs/v1.4_plan.md: "CC0 beds only with verified-clean licenses,
else procedural beds stay." External CC0 download provenance cannot be
verified offline to the standard the plan demands, so C4b = **more procedural
beds** in core/audio.py (zero licensing risk, zero new deps).

## New beds (same signature `fn(dur, cuts, t_typing=None)`, same mix level)
1. `low_drive`   — 92bpm dark-trap feel: sub sine w/ glide eighths, sparse clap
                   noise at beats 2/4, closed-hat rolls, cut impacts + risers.
2. `sparkle`     — 130bpm bright/upbeat: A-minor pluck arps (fast), four-on-floor
                   kick, offbeat open hat, cut crash. Lighter mix than synthwave.
3. `ambient_glow`— beatless pad bed: slow-swelling stacked saw pads cycling the
                   CHORD colors, soft noise wash, gentle swell into each cut.
                   For voice-heavy explainers where drums fight the VO.

## Wiring (all single-site)
- core/audio.py: three new bed_* fns + BEDS entries + scan_music() labels.
- Nothing else changes: app.py meta derives from A.BEDS, music_preview gates on
  BEDS.get, _normalize_music already routes procedural names, UI dropdown lists
  META.music automatically.

## Gates
- scratch probe: render each bed 8s + 30s, ffprobe duration, RMS sanity.
- tests/test_music_beds.py: every BEDS entry runs at 4/12/30s, exact sample
  count, peak in (0, 0.95], no NaN; wired into smoke suite.
- full smoke + golden untouched (no pixel change).
